# Photo & signature POD — Driver app

Complete delivery with multimedia proof (photo + signature), including contactless rules.

## Steps

1. Arrive at drop-off (respect geofence if enforced).
2. **Mark as Delivered** / complete.
3. Capture **photo** when required; **signature** on the pad (Clear to retry).
4. Confirm complete — order delivered for customer, restaurant, admin.

API rejects → missing proof when required, or too far from coordinates.
