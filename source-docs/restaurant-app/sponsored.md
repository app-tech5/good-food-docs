# Sponsored visibility — Restaurant app

Launch paid search / home banner campaigns from the partner app.

## Steps

1. Prefer **live** API mode for real campaigns.
2. Open **Sponsored listings**.
3. New campaign — headline, daily bid, placement (search / banner / both).
4. **Launch**; confirm under My campaigns.
5. Check customer home/search and admin [sponsored inventory](../admin-app/sponsored.md).

API: **`/api/sponsored`**.
