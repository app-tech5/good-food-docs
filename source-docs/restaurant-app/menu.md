# Menu management — Restaurant app

Categories, dishes, prices, photos, variants, availability (86).

## Steps

1. Drawer → **Menu**.
2. Add/edit categories and items; set price and photo.
3. Toggle availability when an item is 86’d.
4. Customer menu should refresh without the unavailable item ([menu & basket](../customer-app/menu-cart.md)).

Admin can also curate centrally: [catalog](../admin-app/catalog.md).
