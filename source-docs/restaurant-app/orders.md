# Incoming orders — Restaurant app

Accept / reject live tickets and advance status through prep / ready.

## Prerequisites

- Restaurant app live ([getting started](./getting-started.md))
- Restaurant open / can fulfill

## Steps

1. Keep restaurant **open**.
2. Watch orders list — accept what you can cook; reject with a reason when not.
3. Advance status as food progresses; mark ready for courier or pickup.
4. Optional: run the same pipeline on [Kitchen Display](./kitchen-display.md).
