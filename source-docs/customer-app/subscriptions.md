# Membership plans — Customer app

Subscribe to customer-targeted plans (free delivery, discounts, etc.).

## Steps

1. Admin has active plans with `target = customer` ([subscriptions](../admin-app/subscriptions.md)).
2. Customer app → Subscriptions / membership.
3. Subscribe and complete payment.
4. Confirm plan active; place an order that should receive benefits.
