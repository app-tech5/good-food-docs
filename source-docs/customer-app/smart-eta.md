# Smart delivery ETA — Customer app

ETA chip on restaurant / checkout paths from kitchen load + travel estimates.

## Demo

1. Create kitchen load (several accepted orders) or use seed activity.
2. Open restaurant detail / checkout — note ETA range (e.g. 26–36 min).
3. Explain OSRM when online; heuristic travel when not.
