# Menu & basket — Customer app

Browse categories, add items with quantities, review the cart.

## Smoke test

1. On a restaurant menu, add 2+ items (variants if exposed).
2. Confirm quantity steppers and **View Cart** / tab badge.
3. Open cart — change qty, remove a line, confirm totals.
4. Continue to [checkout](./checkout.md).

86’d items should not be orderable after restaurant toggles availability ([menu](../restaurant-app/menu.md)).
