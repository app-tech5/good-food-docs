# Browse & discover — Customer app

Home, search, and nearby map — how customers find restaurants before opening a place.

## Prerequisites

- API + customer app live ([getting started](./getting-started.md))
- At least one activated restaurant with products

## Smoke test

1. Open home — Delivery / Pickup toggle, categories, promo / Special Offers cards load from API.
2. Open **Search** — type a restaurant or dish keyword; open a result.
3. Open nearby **map** — pins + swipeable card (not the post-checkout tracking map).
4. Tap a restaurant → continues to [restaurant details](./restaurant-page.md).

Empty home → API URL, migrations, restaurant `isActivated`, or network.
