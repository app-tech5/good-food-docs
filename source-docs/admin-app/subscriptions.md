# Subscription plans — Admin app

CRUD for customer / driver / restaurant tiers.

## Steps

1. Open **Subscriptions**.
2. Edit seeded plans or create new (target, price, cycle, benefits, active).
3. Verify each mobile role’s subscribe screen lists the plan.
