# Partners & users — Admin app

Restaurants, drivers, and customer accounts.

## Steps

1. **Restaurants** — activate/close; edit profile fields (hours, address, commission, categories).
2. **Drivers** — approve before they go online; suspend when needed.
3. **Users** — support edits / abuse suspension; pair with [orders](./orders.md).
