# Orders & support — Admin app

Investigate live and past marketplace orders from one list.

## Steps

1. Open **Orders** on an incident.
2. Find by customer / restaurant / id.
3. **View** full detail (lines, payment, driver, timeline) before changing status.
4. Cross-check mobiles only after the API record looks wrong.
