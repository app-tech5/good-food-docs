# Languages & RTL — Admin app

Language catalogue and marketplace default (EN/FR/ES/AR).

## Steps

1. Open **Languages** after migrations.
2. Confirm `en`, `fr`, `es`, `ar`; set default.
3. Keep Arabic RTL flag on.
4. Verify mobile pickers: [customer](../customer-app/languages-rtl.md), [driver](../delivery-app/languages.md), [restaurant](../restaurant-app/languages.md).
