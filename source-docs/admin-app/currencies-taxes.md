# Currencies & taxes — Admin app

Money language and tax catalogues for carts and reports.

## Steps

1. **Currencies** — create/edit code, symbol; set main currency in [app settings](./app-settings.md).
2. **Taxes** — VAT/GST/sales rates; attach as your forms require.
3. Force clients to reload settings; verify menu, cart, wallet, earnings symbols.
4. Test checkout tax lines vs finance expectations.
