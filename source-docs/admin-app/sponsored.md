# Sponsored inventory — Admin app

Operator oversight of restaurant-created campaigns.

## Steps

1. Open **Sponsored listings**.
2. Review active/past campaigns (restaurant, placement, status).
3. View detail / intervene if a creative should not stay live.
4. Cross-check [restaurant sponsored](../restaurant-app/sponsored.md) and customer feed.
