# Coupon codes — Admin app

Redeemable codes with limits and expiry.

## Steps

1. Open **Coupons**.
2. Create code (min order, max uses, per-user, first-order, expiry).
3. Apply at customer cart / checkout on a test order.
4. Retire codes that are no longer funded.
