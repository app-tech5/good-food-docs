# Marketplace settings — Admin app

Cross-cutting flags: timezone, COD, delivery defaults, commission baseline, channels.

## Steps

1. Open **App Settings** → View active app record.
2. Set timezone, default language, delivery fee/distance, COD.
3. Align currency, taxes, gateways for the launch city.
4. Enable only channels you will operate ([order channels](./order-channels.md)).
5. Run one full order before inviting real restaurants.
