# Promo campaigns — Admin app

Campaign objects: type, discount, schedule, scope.

## Steps

1. Open **Promotions**.
2. Create campaign (%, fixed, free delivery, etc.) with schedule and scope.
3. Activate; place a customer order that should receive the discount.
4. Confirm appearance on customer home / restaurant surfaces.
