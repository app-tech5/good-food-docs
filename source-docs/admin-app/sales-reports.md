# Sales reports — Admin app

Read-only snapshots of marketplace revenue for a period — either platform-wide or scoped to one restaurant. There isn't much to "configure" here beyond picking what to generate/view; the value is in reading the numbers correctly.

## What you're looking at

| Field | Meaning |
|---|---|
| **Restaurant** | The report's scope — blank/unset means platform-wide across all restaurants |
| **Start Date / End Date** | The period the totals below cover |
| **Total Sales** | Gross revenue for the period |
| **Total Orders** | Order count for the period |
| **Average Order Value** | Total Sales ÷ Total Orders |
| **Sales By Category** | Revenue split across menu categories — the bar chart and breakdown table show the same numbers two ways |
| **Delivery Fees** | Delivery fee revenue collected in the period |
| **Taxes Collected** | Tax amount collected in the period |
| **Generated By** | Which admin/user triggered the report |
| **Status** | `pending`, `completed`, or `failed` — wait for `completed` before trusting the numbers |

## How to set it up

1. Complete some real or demo orders across the period you want to analyze.
2. Open **Sales reports** and generate/select a period (platform-wide, or scoped to a restaurant if that's how your build's report generation is triggered).
3. Wait for **Status** to reach `completed`.
4. Read **Total Sales**, **Orders**, **Average Order Value** for the headline numbers, then check **Sales By Category** for what's actually driving revenue.
5. Use this before partner conversations (renewal, commission negotiation); use [Earnings](./earnings.md) instead when you specifically need the platform/restaurant commission split rather than gross revenue.

## Verify

| Check | Expect |
|---|---|
| Generate a report over a period with completed orders | Status reaches `completed`; Total Orders matches your test order count |
| Average Order Value | Equals Total Sales ÷ Total Orders |
| Sales By Category chart | Sums to (approximately) Total Sales minus fees/taxes not tied to an item category |
