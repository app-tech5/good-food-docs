Marketplace app settings

App Settings hold default language, timezone, cash-on-delivery, delivery fee defaults, maximum delivery distance, and related flags. Commission baselines and channel hooks often live here too.

Before launch in a city

  1. Open Settings → App Settings and View the active app record.
  2. Set timezone, default language, delivery fee / distance, and COD according to local rules.
  3. Align currency, taxes, and gateways with that same market.
  4. Enable only the order channels you will actually operate.
  5. Run one full order in that configuration before inviting real restaurants.
