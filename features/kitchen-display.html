Kitchen Display (KDS)

Paperless kitchen board for restaurant staff: tickets from live orders, tuned for prep speed—not just a chatty order list.

Restaurant app Live tickets Demo seeds

What it is

The restaurant app includes a Kitchen Display screen (KitchenDisplayScreen) wired into the drawer / settings navigation. It focuses on kitchen-ready tickets so cooks can move orders through prep without managing the full owner dashboard.

How it fits the loop

Customer places order → restaurant accepts → KDS shows the ticket → kitchen progresses status → driver pickup. The same order documents power admin earnings and driver logistics.

Demo data

Migration 41-orders-seed-kds-demo-tickets.js seeds kitchen-oriented demo tickets so screenshots and demos are not empty. Run backend migrations after install (see Backend — Getting Started).

Where to look

  • restaurant-app/screens/KitchenDisplayScreen.js
  • Drawer / settings stack registration in restaurant navigation
  • my-backend/migrations/41-orders-seed-kds-demo-tickets.js
