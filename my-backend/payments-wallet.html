Payments & wallet

Gateways, checkout initialize, wallet ledger, cashback, and instant refunds — money rules the apps only display.

Gateways Wallet Refunds

Money that stays coherent across apps

Checkout and wallet top-ups succeed only when the API knows which gateways are active, can initialize payment sessions, and can post ledger movements (pay, cashback, refund to wallet). Front-ends never invent balances.

Gateway catalogue operators configure

Admin enables Stripe / PayPal / Paystack / Flutterwave / Razorpay (and related methods). The API is what checkout and top-up call. UI guide: Payment gateways.

Wallet balance customers trust

Balance, top-up, cashback on delivered orders, and instant refund to wallet on cancel are ledger behaviours owned by the backend. Customer UI: Wallet & cashback.
